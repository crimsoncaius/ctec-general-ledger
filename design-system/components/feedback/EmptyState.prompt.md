Explains which kind of emptiness the user is looking at, and offers a next step only when their capabilities allow one.

```jsx
<EmptyState kind="no-match" icon="search-x" title="No batches match these filters"
            description="Clear the status filter to see all 42 batches in this company." />
```

Distinguish no data, no matching data, no company access and no available action — never one generic "Nothing here".
